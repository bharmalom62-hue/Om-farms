OMKARA FARMS V2.2 - ANDROID APP PROJECT

This is an Android Studio project wrapping the saved Omkara Farms V2.2 web app in an offline WebView.

BUILD APK:
1. Install Android Studio on a computer.
2. Open this extracted folder (OmkaraFarmsAndroid) in Android Studio.
3. Allow Gradle sync and install Android SDK Platform 35 if prompted.
4. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Find the APK at app/build/outputs/apk/debug/app-debug.apk
6. Transfer the APK to your Android phone and install it. You may need to allow installation from that file manager.

The app stores its records in the WebView local storage on that device. Use the app's backup/export feature regularly; clearing app data or uninstalling may erase local records.
