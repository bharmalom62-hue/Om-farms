BUILD OMKARA FARMS V2.2 APK USING ONLY YOUR PHONE

This project includes a GitHub Actions workflow at .github/workflows/build-apk.yml.
You do not need Android Studio or a PC. A GitHub account and internet access are needed.

1. Download and extract Omkara_Farms_V2.2_Android_Studio_Project.zip on your phone.
2. In Chrome, open https://github.com and sign in (create a free account if needed).
3. Create a new repository named OmkaraFarmsAndroid. Public or private is your choice.
4. Upload the CONTENTS of the extracted project folder, including the hidden .github folder.
   Important: the workflow file must be at .github/workflows/build-apk.yml in the repository.
   If the phone's file picker hides .github, use GitHub's web editor to create that file and paste
   the contents from BUILD-APK-FROM-MOBILE.txt is not enough; use the actual build-apk.yml file.
5. Open the repository's Actions tab. If prompted, enable GitHub Actions.
6. Select "Build Omkara Farms APK" > "Run workflow" > "Run workflow".
7. Wait until the run finishes with a green check. Open that run, scroll to Artifacts, and download
   Omkara-Farms-v2.2-debug-apk. Extract the downloaded artifact ZIP to get app-debug.apk.
8. Tap app-debug.apk to install. If Android asks, allow Chrome/Files to install unknown apps.

The APK is a debug build for testing, not a Play Store release. Keep your farm data backed up
using the app's Backup/Export feature. Uninstalling or clearing app data can erase local records.

IF GITHUB DOES NOT LET YOU UPLOAD THE HIDDEN .github FOLDER:
A. In your repository, tap Add file > Create new file.
B. For the filename enter exactly: .github/workflows/build-apk.yml
C. Paste the workflow below, then tap Commit changes.

--- START build-apk.yml ---
name: Build Omkara Farms APK

on:
  workflow_dispatch:

permissions:
  contents: read

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout source
        uses: actions/checkout@v4
      - name: Set up JDK 17
        uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '17'
      - name: Set up Android SDK
        uses: android-actions/setup-android@v3
      - name: Install Android SDK packages
        run: sdkmanager "platforms;android-35" "build-tools;35.0.0"
      - name: Set up Gradle
        uses: gradle/actions/setup-gradle@v4
        with:
          gradle-version: '8.9'
      - name: Build debug APK
        run: gradle --no-daemon assembleDebug
      - name: Upload APK
        uses: actions/upload-artifact@v4
        with:
          name: Omkara-Farms-v2.2-debug-apk
          path: app/build/outputs/apk/debug/app-debug.apk
          if-no-files-found: error
--- END build-apk.yml ---
